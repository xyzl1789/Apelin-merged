# Luros 1.0.4 增量融合验收

## 功能范围

- 同一服务商最多九个账号；首账号沿用旧凭据，附加账号使用规范的 `#2` 至 `#9` 标识。
- 模型选择、默认辅助模型、待发送消息及派生会话携带账号身份，不保存密钥。
- 模型页进入时拉取列表，手动刷新显示原位进度；保留本地备注与模型能力设置。
- 模型选择器增加独立用量入口；输入框原有余额胶囊和原余额详情继续保留。
- 新额度入口支持 `https://100milionseek.top/v1` 的代币响应头；其他中转保留探测流程。
- 货币金额显示两位小数，代币、百分比与用量窗口各自格式化。查询失败统一显示“无法查询用量”。
- 退出先使账号代次失效，阻止迟到登录、验证及刷新恢复凭据；共享密钥池仅在最后一个账号离开时清理。
- 被动响应头通过持久 UUID 代次及文件锁跨工作进程检查，旧观察器不能重建已清除额度池。
- 新文案使用独立 `Quota` 字符串表：50 条键，每条十三种语言。原字符串表与实时活动资源不变。

## 已执行的静态检查

- 无障碍标签可达性检查。
- 持久化读取检查、递归删除变量保护检查、Objective-C 数据桥接检查。
- 三份字符串目录的语言完整性；新额度表的重复键、十三语言及非空翻译检查。
- 三份字符串目录的格式占位符检查。
- 额度表的非插值字面量引用检查，以及新增账号请求构造器的参数顺序人工与源码核对。

这些检查不证明 Swift 类型检查、资源打包或真机行为通过。

## 必须补跑的自动化验收

- 在具备项目要求的 Xcode 环境执行 `make check`，并运行完整 Swift 测试。
- 定向套件包括 `ProviderQuotaTests`（25 项）、`AccountDeskQuotaTests`（1 项）以及 `AccountDeskTests` 新增的 11 项账号回归。
- 确认命名账号请求拒绝跨服务商、前导零、嵌套后缀和缺少服务商的定向额度查询。
- 确认取消后迟到的模型验证、OAuth 登录及主动额度回包不会恢复退出前的数据。
- 确认两个缓存实例及真实独立工作进程之间的文件锁和代次失效；读取或隔离失败不得覆盖旧缓存。
- 确认专用站点代币精度与异常头处理，认证请求不会跟随重定向。
- 确认独立额度传输作用域保留原 HTTP 客户端、模型转换、兼容性转换及服务商行为识别。
- 运行目录键提取检查，验证编译器提取的插值键与 `Quota` 表一致。

本机完整检查在通过 51 项决策清单后因缺少 `xcodebuild` 停止。翻译脚本的 InfoPlist 分支也受本机 `plutil` 参数差异阻塞；仅字符串目录分支已独立执行通过。上述自动化验收均不能记为完成。
