# 原生逆向分析 0.1.3

提供独立安装包，让 AI 按需使用原生 Mach-O 函数分析、控制流、引用查询和 Ghidra C 伪代码。

- 编译成功却找不到安装包：现在成功构建后会提供 roothide 与 rootless 两份 `.deb`，不需要重新安装整个主应用。
- 超过 32 MiB 的薄 Mach-O 无法分析：输入上限提高到 48 MiB，路径、只读附件和工作进程使用一致边界；间接调用与跳转表的恢复能力不因此改变。
- 不知道附件是否来自同一轮构建：程序、安装清单和软件包使用统一的 CI 序号版本，打包前后核对架构、签名权限、文件摘要和完整对应源码。
- 需要离线查看或重建：每个安装包均包含完整对应源码和上游许可，发行附件另附源码归档及包内核验报告。

这是 CI 预发行构建。编译和包内静态核验不代表已完成安装、主应用工具发现或真实设备功能验收；不会自动安装到设备。

roothide 选择文件名含 `iphoneos-arm64e` 的安装包，rootless 选择含 `iphoneos-arm64` 的安装包；下载后用 `SHA256SUMS` 核对附件。
